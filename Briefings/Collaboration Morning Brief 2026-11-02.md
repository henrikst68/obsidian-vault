# 🗓️ Collaboration Morning Brief — Monday, 2 November 2026

## 🔵 Microsoft Teams
- Teams is rolling out AI-powered, context-aware phishing detection starting in early November, using conversation context "without retaining message content" to flag suspicious external first-contact chats, with GA expected worldwide by mid-December. The rollout is part of a targeted release phase expected to end by mid-November, with the new security feature likely reaching general availability worldwide between early and mid-December, using conversation context (without retaining message content) to identify phishing and suspicious behavior in higher-risk messaging scenarios, such as external first-contact chats.
- Microsoft's November roadmap bundle extends Teams security further, adding malicious QR-code detection, meeting-impersonation protection, and scam detection built into the Facilitator agent alongside the phishing feature. Teams Security Continues to Get Smarter - AI-powered phishing detection, Malicious QR-code detection, Meeting impersonation protection, Facilitator gains scam detection.
- Work IQ's real-time transcript access for Teams meetings reaches general availability this month; Work IQ access takes effect on November 14, 2026, and if apps in your organization already receive real-time transcripts through Work IQ, admins should turn on Work IQ access before that date to keep them working.

## 🤖 Copilot & AI in Teams
- Microsoft confirmed Work IQ is evolving into a broader orchestration layer, connecting Copilot, organizational knowledge, agents, and Microsoft 365 services, with upcoming capabilities including Microsoft IQ, a unified intelligence layer for agents to discover and reason over organizational knowledge, plus new REST endpoint tools and retrieve/upload capabilities for agents.
- Microsoft quietly pushed back a licensing change originally slated for today: usage-based billing for new Microsoft 365 Copilot Business licenses, previously communicated as November 2, 2026, will now be enabled by default starting December 1, 2026 for subscriptions purchased through CSP.
- Model choice is expanding in Copilot Chat: usage-based billing models, including GPT-6 Astra and Claude Fable 5.1, will be available in Microsoft Copilot Chat and Copilot in Word, Excel, and PowerPoint starting November 2026.

## 🔗 Ecosystem & Integrations
- SharePoint/OneDrive admins face a deadline: from mid-November 2026, new agent creation moves to Copilot Agent Builder, while existing App Builder access continues until November 30, 2026.
- Azure Communication Services, Microsoft's CPaaS play competing with Twilio, is retiring as a standalone product, with no new sign-ups for the retiring services from 23 October 2026.
