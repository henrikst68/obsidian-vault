# Coffee Roasting (BBQ Rotisserie)

Roasting green coffee beans in a perforated drum on the BBQ rotisserie. Roasted beans feed into [[Areas/Espresso/README|Espresso]].

## Contents
- [[Roasting Guide]] — process, targets, safety and how to run experiments
- [[Roast Session Template]] — copy this for every roast (in `Templates/`)
- [[Roast Log]] — overview of all sessions (Dataview table)
- `Sessions/` — one note per roast, named `YYYY-MM-DD Roast NNN`
- `Photos/` — result photos, named `YYYY-MM-DD-roast-NNN.jpg`

## Workflow
1. Create a new note in `Sessions/` from [[Roast Session Template]].
2. Fill in the plan section *before* lighting the grill (bean, batch weight, which single variable you change).
3. Log the timeline during the roast (phone in hand, timer running).
4. Weigh after cooling, take the result photo, add it to `Photos/`.
5. Fill in the tasting section after rest (at least 24 h, for espresso 5–10 days).
6. Decide the next change and write it in "Next roast".
